01 / AI CAREER ASSISTANT

Student Profile Analyser

AI-powered profile analysis & personalized career assistance.

Analyses a student's profile and extracts relevant information such as education, skills, projects and experience. The system can use this information to generate personalized outputs, including company-specific cover letters based on the requirements of a target role.

  • Analyses student profile documents
  • Extracts skills, experience and projects
  • Uses semantic retrieval for relevant information
  • Generates personalized profile insights
  • Creates company-specific cover letters
  • Uses LLMs for contextual generation

02 / DOCUMENT INTELLIGENCE

PDF Chatbot

Ask questions and retrieve answers directly from PDF documents.

A Retrieval-Augmented Generation application that processes PDF documents, splits them into meaningful chunks, creates embeddings and stores them for semantic retrieval. Users can then ask natural language questions and receive answers grounded in the uploaded document.

  • Upload and process PDF documents
  • Extract and preprocess document text
  • Chunk and tokenize large documents
  • Generate semantic embeddings
  • Perform vector similarity search
  • Generate context-grounded answers with an LLM

About the Work

These projects were developed to explore the practical engineering of LLM-powered applications beyond simple model prompting. The implementations focus on connecting language models with external information through document processing, embeddings, vector retrieval and RAG pipelines.

The goal is to build systems where an LLM can work with relevant user-provided information and produce useful, context-aware outputs.
