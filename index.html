PROJECT 02

PDF Chatbot

RAG-based document question answering

A Retrieval-Augmented Generation application that allows users to interact with PDF documents through natural language. Relevant document context is retrieved before an LLM generates the final response.

  • Accepts PDF documents as knowledge sources
  • Extracts and preprocesses document text
  • Splits documents using chunking techniques
  • Converts document content into embeddings
  • Stores and retrieves document vectors
  • Performs semantic similarity search
  • Answers questions using retrieved context

About

Building Beyond Simple LLM Calls

These projects explore the practical engineering involved in building LLM-powered applications that work with external information. Rather than treating a language model as a standalone chatbot, the systems combine document processing, chunking, embeddings, vector retrieval and prompt-based generation to provide context-aware outputs.


The projects were developed as hands-on explorations of Generative AI application development, with a focus on understanding how RAG pipelines, semantic search and LLM APIs can be combined to solve practical problems.
